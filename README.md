# Othello analyst

Notes on how this search decides a move on 64 squares.

## Position representation

Black and white are each a `bigint` bitboard. Legal moves and flips are generated by shifting along the eight rays and stopping when a same-color disc closes a run of the opponent.

## Search

Root search is iterative deepening. Each depth uses principal variation search (PVS) with alpha-beta, a transposition table of size `2^18`, and move ordering from TT move, killers, history, corners, and static square weights.

Search stops when the time budget is exhausted or the configured max depth is reached. The reported “best” move in the middlegame is therefore the best line found inside that bound, not a claim of perfect play from the opening.

## Evaluation

Interior nodes score a position with a hand-tuned heuristic:

- square weights (corners high, X-squares and C-squares low)
- corner ownership
- penalties on X/C squares while that corner is still empty
- mobility (legal-move count difference)
- frontier discs
- late-game disc count as empties shrink

Scores are from the side to move.

## Exact endgame

When 10 or fewer squares are empty, search switches to exact solve through the terminal position. The score is the disc difference scaled by 10000 (`+n discs (exact)`). Above that empties threshold, leaf evaluation stays heuristic.
